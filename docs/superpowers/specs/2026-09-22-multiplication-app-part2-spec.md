# 설계 파트 2: 결과, 기록, 인증 및 DB 연동 (Design Spec)

## 1. 개요 (Overview)
기존에 구현된 카테고리 대시보드와 퀴즈 화면(Endless 모드)을 확장하여, 실제 앱으로서 기능할 수 있도록 **10문제 단위 세션화, 결과 분석, 로그인 인증 및 클라우드(Supabase) 데이터 저장**을 구현합니다.

## 2. 상세 요구사항 (Detailed Requirements)

### 2.1. 결과 화면 (Result Screen)
- **세션 종료 조건**: 퀴즈 화면에서 10문제를 모두 풀면 즉시 결과 화면으로 전환됩니다.
- **표시 데이터**:
  - 최종 점수 (정답 수 × 10점, 100점 만점)
  - 이번 세션에서 획득한 총 경험치 (EXP +150 등)
- **상세 분석 UI**: 10개의 문제에 대한 정답/오답 상세 리스트 노출 (문제 식, 내가 쓴 답, 실제 정답).
- **UX 및 애니메이션**: 100점 만점일 경우 특별한 폭죽 애니메이션(Framer Motion)과 칭찬 메시지 노출.
- **내비게이션 버튼**: `메인으로 돌아가기`, `다시 풀기`

### 2.2. 기록 화면 (History Screen)
- **진입점**: 메인 대시보드 하단의 `🏆 내 성취도 보러가기` 버튼 클릭 시 진입.
- **데이터 로드**: 사용자의 과거 학습 세션 기록을 최근 날짜순으로 정렬하여 리스트업.
- **리스트 아이템 디자인**: 카테고리 이름(예: 구구단), 점수(예: 80점), 획득 EXP, 풀이 날짜 표시.
- **내비게이션 버튼**: 상단에 `← 메인으로 돌아가기` 배치.

### 2.3. 로그인/회원가입 화면 (Auth Screen)
- **접근 통제**: 사용자가 앱에 접속 시, 인증된 세션(Supabase Auth)이 없으면 퀴즈나 메인을 숨기고 즉시 로그인 화면을 표시합니다.
- **UI 폼 구성**: 이메일 입력칸, 비밀번호 입력칸, `로그인` 버튼, `회원가입` 버튼.
- **에러 처리**: 잘못된 비밀번호, 존재하지 않는 이메일 등의 인증 실패 시 사용자 친화적인 에러 메시지(Alert 또는 하단 텍스트)를 표시.

### 2.4. 클라우드 DB 및 상태 연동 (Supabase Integration)
- **Auth Provider**: 최상단 레이아웃에 AuthContext를 두어, 유저 세션 정보를 하위 컴포넌트 전체에 제공.
- **데이터 갱신 (퀴즈 종료 시)**:
  - 10문제를 풀고 Result로 넘어가는 순간, `learning_sessions` 테이블에 1개 Row를 INSERT.
  - 동시에 `profiles` 테이블에 유저의 누적 EXP와 Level을 계산하여 UPDATE.
- **데이터 패치 (메인 로드 시)**:
  - 로그인 시 `profiles` 테이블에서 유저의 누적 레벨과 경험치를 가져와 전역 상태(또는 Context)로 유지.
  - 메인 화면과 퀴즈 화면의 상단바(Header)는 이 전역 데이터를 기반으로 캐릭터와 EXP 바를 표시.
