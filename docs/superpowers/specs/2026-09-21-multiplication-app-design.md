# 초등학생 3학년 대상 곱셈 학습 프로그램 설계 명세서 (Design Spec)

## 1. 개요 (Overview)
- **목적**: 초등학교 3학년 학생들의 곱셈 연산 능력을 향상시키기 위한 자기주도 학습용 웹 애플리케이션
- **플랫폼**: 웹 애플리케이션 (PC 및 태블릿 브라우저 환경 최적화)
- **핵심 특징**: 
  - 정답 직접 입력 방식 (주관식)
  - 캐릭터 성장 시스템(Gamification)을 통한 강력한 학습 동기 부여
  - 학부모 및 학생 스스로 성취도를 파악할 수 있는 기록 관리

## 2. 아키텍처 및 기술 스택 (Architecture & Tech Stack)
- **프론트엔드**: Next.js (App Router), React, TailwindCSS
- **백엔드/DB/인증**: Supabase (PostgreSQL DB, Auth 내장 모듈 사용)
- **배포**: Vercel (예정)

## 3. 핵심 기능 (Core Features)

### 3.1. 문제 출제 (4가지 카테고리)
- 클라이언트(브라우저)에서 무작위 난수(Math.random)를 통해 매번 새로운 문제를 즉석 생성합니다.
1. **구구단**: 2~9 × 1~9
2. **두자리 × 한자리**: 10~99 × 2~9
3. **세자리 × 한자리**: 100~999 × 2~9
4. **두자리 × 두자리**: 10~99 × 10~99

### 3.2. 학습 및 인터랙션 (UX)
- 문제당 제한시간은 따로 두지 않아 아이들이 스트레스 없이 풀 수 있도록 합니다.
- 정답 입력칸에 숫자를 입력하고 엔터(Enter)키를 누르면 다음 문제로 즉시 넘어가도록 하여 마우스 조작을 최소화합니다.
- 오직 숫자만 입력 가능하도록 방어 로직(Validation)을 적용합니다.

### 3.3. 캐릭터 성장 시스템 (Gamification)
- **경험치(EXP) 획득**: 난이도에 따라 지급 (예: 구구단 10점, 두자리x한자리 20점 등)
- **레벨업 및 캐릭터 진화**: 일정 EXP 도달 시 레벨이 오르며, 특정 구간(예: Lv.1, 5, 10, 20)에서 캐릭터 이미지가 변경됩니다. (기본 에셋 활용: 알 ➡️ 아기 몬스터 ➡️ 멋진 몬스터 등)

## 4. 데이터베이스 스키마 (Database Schema - Supabase)

### 4.1. `profiles` (사용자 프로필 테이블)
- `id` (uuid, PK): Supabase Auth의 유저 ID와 연동
- `email` (string)
- `level` (integer, default: 1): 현재 레벨
- `exp` (integer, default: 0): 현재 누적 경험치
- `created_at` (timestamp)

### 4.2. `learning_sessions` (학습 단위 기록 테이블)
- `id` (uuid, PK)
- `user_id` (uuid, FK -> profiles.id)
- `category` (string): 푼 카테고리 이름
- `total_questions` (integer): 전체 문항 수 (예: 10)
- `correct_count` (integer): 맞춘 문항 수
- `earned_exp` (integer): 해당 세션에서 획득한 총 경험치
- `created_at` (timestamp)

## 5. UI 화면 구성 (UI/UX)
- **공통 상단바 (Header)**: 내 캐릭터 이미지, 현재 레벨(Lv), 경험치 게이지 바(Progress Bar) 상시 노출
- **메인 화면 (Home)**: 4가지 학습 카테고리 입장 버튼
- **학습 화면 (Quiz)**: 상단에 진행도 (예: 4 / 10) 표시, 화면 중앙에 큰 글씨의 곱셈 문제와 입력창 배치
- **결과 화면 (Result)**: "EXP +150 획득!" 이라는 문구와 화려한 애니메이션, 맞춘 문제/틀린 문제 결과 요약 노출
- **학습 기록 화면 (History)**: 과거에 푼 세션 목록과 점수를 날짜순으로 나열
- **로그인/가입 화면 (Auth)**: 이메일과 비밀번호를 이용한 간편 로그인 폼

## 6. 예외 처리 및 방어 로직 (Error Handling)
- 비정상적인 문자열 입력 및 빈칸 제출 버튼 클릭 비활성화 방어.
- 인터넷 끊김 발생 시 결과 저장 실패 알림 팝업 및 로컬 상태 임시 유지.
